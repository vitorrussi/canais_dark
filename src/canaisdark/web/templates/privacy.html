Política de privacidade

Este é um sistema de uso pessoal para gerenciar canais do YouTube. Não é um serviço aberto ao público e não coleta dados de visitantes.

Dados acessados

  • YouTube: ao conectar um canal, o sistema usa a permissão para enviar vídeos (sempre como privados) e ler o nome do canal conectado.
  • Google Drive: usa apenas a permissão drive.file, que dá acesso somente aos arquivos e pastas criados pelo próprio sistema. Não lê o restante do seu Drive.

Armazenamento

Os tokens de acesso ficam criptografados no servidor do próprio dono do sistema. Nenhum dado do Google é vendido, compartilhado com terceiros ou usado para publicidade.

Revogação

A conexão pode ser removida a qualquer momento no sistema ou em myaccount.google.com/permissions.
