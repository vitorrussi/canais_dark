Conectar o Claude

O Claude Code acessa este estúdio pelo servidor MCP e executa as tarefas que o site cria. Cada pessoa usa o seu próprio token.

1. Seu token de API

Por segurança, o servidor guarda só um hash do token e não consegue mostrá-lo de novo. Se perdeu o seu, gere outro — o anterior deixa de valer (inclusive no Claude Code já configurado).

{% endif %}

2. Registrar o MCP no Claude Code

Rode uma vez no terminal. Use --scope user para valer em qualquer pasta.

{{ command }}
{% if not token %}

Troque <SEU_TOKEN> pelo seu token (ou gere um novo acima: o comando já virá preenchido).

Endereço do MCP: {{ mcp_url }}. Em produção, o acesso externo exige também o Service Token do Cloudflare Access (ver docs/mcp-tools.md).

3. Usar

  1. Abra o Claude Code (claude) e digite /mcp: o servidor canais deve aparecer como conectado.
  2. Na página de um vídeo, copie o prompt para o Claude e cole no Claude Code. Ou processe tudo de uma vez:
{{ process_all_prompt }}

Atalho no Claude Code: /mcp__canais__process_pending.

Problemas comuns

  • Falhou ao conectar: o servidor (make dev) está rodando? A porta é 8123?
  • 401 / token inválido: gere um novo token e refaça o comando (claude mcp remove canais antes).
  • Host não permitido (421): acesse por localhost ou adicione o domínio em MCP_ALLOWED_HOSTS.
  • Tarefa “em andamento” travada: a reserva expira em 30 min, ou cancele pela página do vídeo.
